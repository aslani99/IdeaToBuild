# PRODUCT SPECIFICATION — IdeaToBuild

## چشم‌انداز محصول

یک پلتفرم امن شخصی برای مدیریت ایده، دانش، برنامه‌ریزی و فایل. ویژگی محوری و مهم‌ترین بخش محصول **مدیریت ایده (Idea Management)** است.

محصول ترکیبی است از: مدیریت ایده، مدیریت دانش شخصی، یادداشت، پروژه، وظیفه، برنامه‌ریزی، تقویم، تایم‌لاین، کانبان، گانت، جدول، گراف روابط، مدیریت فایل، ذخیره‌سازی ابری، جستجو، دسته‌بندی، برچسب، موردعلاقه‌ها، اخیرها، سطل زباله، بازیابی، تاریخچه‌ی نسخه، عملکرد آفلاین، همگام‌سازی ابری، بک‌آپ، مدیریت حساب امن، بین‌المللی‌سازی، دسترسی‌پذیری، تم روشن/تیره.

قانون سخت: **هیچ AI درون محصول تولیدی وجود ندارد.**

## اولویت توسعه

Phase 0 (بنیاد) → Phase 1 (Windows Desktop) → Phase 2 (Web) → Phase 3 (Android) → Phase 4 (iOS)

دسکتاپ اول ساخته می‌شود، اما معماری از روز اول چندسکویی است.

## موجودیت‌های اصلی (Phase 3 و بعد)

هر Idea شامل: عنوان، توضیح، محتوای غنی، آیکون، کاور، وضعیت، اولویت، دسته، برچسب، تاریخ ایجاد/ویرایش، یادآور، ددلاین، وظایف، زیروظایف، نقاط عطف، فایل، یادداشت، لینک، رویداد تقویم، روابط، پیشرفت، تاریخچه.

نماهای متعدد روی همان داده: List، Table، Board، Calendar، Timeline، Gantt، Graph، Statistics.

## مدل Workspace

```
User → Workspace → Resources (Ideas, Projects, Tasks, Notes, Files, Folders, Calendar Events, Tags, Categories)
```

حتی نسخه‌ی اول (شخصی) باید معماری آماده‌ی Workspace چندنفره داشته باشد.

## وضعیت سند

این نسخه‌ی خلاصه‌ی Phase 0 است، برگرفته از سند توسعه‌ی اصلی که مالک پروژه ارائه داده. جزئیات کامل هر بخش (ویرایشگر محتوا، تقویم، جستجو، ...) در فازهای مربوطه گسترش می‌یابد.
